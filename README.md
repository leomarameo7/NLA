# NLA

### Description

**Disclaimer: This is very much a work in progress. Use at your own risk and please report any problems to Leonardo Capitani (**leocapi07\@gmail.com**).**

This repository contains data and code to implement Nested Library Analysis (NLA) in R with the [Gaussian Process-EDM](https://tanyalrogers.github.io/GPEDM) approach (Munch, S. & Rogers, T. 2025). NLA was proposed by [Huang et al. 2024](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1011759#sec009): *Detecting shifts in nonlinear dynamics using Empirical Dynamic Modeling with Nested-Library Analysis*.
